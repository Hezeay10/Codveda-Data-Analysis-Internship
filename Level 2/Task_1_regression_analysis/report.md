# Regression Analysis Report

## Objective

To predict stock closing prices using Linear Regression.

## Dataset

Stock Prices Data Set.csv

## Methodology

- Data loading
- Data preprocessing
- Train-test split
- Linear Regression
- Model evaluation
- Data visualization

## Results

Mean Absolute Error:
0.7692

Mean Squared Error:
2.7261

Root Mean Squared Error:
1.6511

R² Score:
0.9997

## Conclusion

The model accurately predicts stock closing prices based on opening prices. The visualization and evaluation metrics demonstrate an excellent model fit.
