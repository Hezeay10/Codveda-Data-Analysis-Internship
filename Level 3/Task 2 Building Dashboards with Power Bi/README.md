# Social Media Sentiment Analysis Dashboard (Power BI)

## Project Overview

This project involves transforming and analyzing a social media sentiment dataset using Microsoft Power BI. The goal was to build an interactive dashboard that provides insights into sentiment patterns, platform performance, user engagement, and posting trends.

The dashboard allows users to explore social media activity through interactive visualizations and filters.

---

## Tools Used

- Microsoft Power BI
- Power Query (Data Cleaning)
- Data Visualization Techniques

---

## Dataset Description

The dataset contains social media posts with information about user activity, sentiment, engagement metrics, and posting details.

### Key Features:

- Text
- Sentiment
- User
- Platform
- Hashtags
- Retweets
- Likes
- Country
- Date
- Time
- Hour

Dataset size:

- 732 social media posts

---

## Data Preparation

The raw dataset was cleaned and prepared using Power Query.

Steps performed:

- Removed unnecessary columns
- Checked and handled missing values
- Converted columns into appropriate data types
- Created date, time, and hour fields
- Prepared the dataset for visualization

---

# Dashboard Features

## KPI Cards

The dashboard includes:

- Total Posts
- Total Likes
- Total Retweets
- Average Likes Per Post

---

## Visualizations

### 1. Sentiment Distribution

Shows the frequency of different sentiment categories.

Key finding:

- Positive sentiment was the most common sentiment category.
- Joy and Excitement were also among the highest categories.

---

### 2. Posts by Platform

Shows social media activity across different platforms.

Key finding:

- Instagram recorded the highest number of posts.

---

### 3. Likes vs Retweets Engagement

A scatter chart showing the relationship between likes and retweets.

Key finding:

- Posts with higher retweets generally received more likes.

---

### 4. Posting Trend Over Time

A line chart displaying changes in posting activity over time.

Key finding:

- Posting activity fluctuated with several peaks and drops.

---

### 5. Posting Activity by Hour

Shows the number of posts created during different hours of the day.

Key finding:

- The highest posting activity occurred around 14:00 (2 PM).

---
