\### Task 1: Data Cleaning and Preprocessing



\*\*Objective:\*\*

Clean and preprocess a raw dataset containing missing values, duplicate records, and inconsistent data formats.



\*\*Tools Used:\*\*

\- Python

\- Pandas

\- VS Code

\- Git \& GitHub



\*\*Data Cleaning Steps Performed:\*\*

\- Loaded the dataset using Pandas

\- Inspected dataset structure and data types

\- Identified and handled missing values

\- Removed unnecessary columns

\- Checked and removed duplicate records

\- Standardized inconsistent date and timestamp formats

\- Separated date and time information into individual columns

\- Exported the cleaned dataset for further analysis
