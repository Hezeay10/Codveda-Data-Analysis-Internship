# Codveda Level 1 Task 3: Basic Data Visualization Report

## 1. Introduction

This project focuses on creating basic data visualizations from a cleaned sentiment dataset. The aim was to identify patterns, distributions, and relationships within the data using Python visualization libraries.

## 2. Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn

## 3. Dataset Description

The dataset contains information about social media posts, including:

- Text
- Sentiment
- Platform
- Likes
- Retweets
- Country
- Posting time

## 4. Data Visualization

### 4.1 Bar Plot: Sentiment Distribution

The bar plot was created to visualize the number of posts belonging to each sentiment category.

This helps understand the overall sentiment distribution in the dataset.

![Sentiment Distribution](plots/sentiment_bar_plot.png)


### 4.2 Line Chart: Average Likes by Hour

The line chart shows the average number of likes received during different hours of the day.

This helps identify engagement patterns based on posting time.

![Hourly Likes Trend](plots/hourly_likes_line_chart.png)


### 4.3 Scatter Plot: Likes vs Retweets

The scatter plot shows the relationship between likes and retweets.

It helps analyze whether posts with higher likes also receive more retweets.

![Likes and Retweets Relationship](plots/likes_retweets_scatter.png)


## 5. Conclusion

The visualizations provided insights into sentiment distribution, engagement trends, and relationships between social media interactions.

This task improved my understanding of using Python visualization tools to communicate data-driven insights effectively.
