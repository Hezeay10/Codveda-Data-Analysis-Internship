# Codveda Level 1 Task 3: Basic Data Visualization

## Project Description
This project focuses on creating basic data visualizations using Python to understand patterns, distributions, and relationships within a cleaned dataset.

## Dataset
The project uses a cleaned sentiment analysis dataset.

The dataset contains information such as:
- Sentiment
- Platform
- Likes
- Retweets
- Country
- Posting time

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Visualizations Created

### 1. Bar Plot
Shows the distribution of different sentiments in the dataset.

### 2. Line Chart
Shows the average number of likes received at different hours of the day.

### 3. Scatter Plot
Shows the relationship between likes and retweets.

## Output
All visualizations were customized with:
- Titles
- Axis labels
- Legends

The plots were exported as PNG images and saved in the plots folder.
